# Internacionalización

## Configuración

`config/packages/translation.yaml`:

```yaml
framework:
    default_locale: es
    translator:
        default_path: "%kernel.project_dir%/translations"
        fallbacks:
            - es
```

`config/services.yaml` expone la variable de entorno `LOCALES` como el parámetro `locales`, utilizado por:

- `App\EventSubscriber\LocaleSubscriber` (lista de locales aceptados).
- `config/packages/twig.yaml` (global de Twig `locales`).
- `App\Controller\Admin\DashboardController::configureDashboard()` para construir el selector de idioma de EasyAdmin.

`.env` incluye `LOCALES='es|en'`.

## Resolución del locale

`App\EventSubscriber\LocaleSubscriber` con prioridad 40 determina el locale de la petición en cada petición principal:

1. Si `_locale` lo proporciona la ruta o la cadena de consulta, y está en la lista permitida, se persiste en la sesión.
2. Se lee el valor de la sesión (o se recurre a `default_locale`).
3. Se valida de nuevo contra la lista permitida.
4. Se aplica con `Request::setLocale($locale)`.

La ruta del panel de administración es `/admin/{_locale}`, por lo que el locale forma parte de la URL; en el sitio público el valor es el que el usuario persistió durante su sesión.

Ver [http-subscribers](06-http-subscribers.md#localesubscriber).

## Archivos de traducción

```
translations/
├── messages.es.yaml                # Cadenas de la aplicación
├── EasyAdminBundle.es.yaml         # Sobreescrituras de EA
├── ArkounayUxMediaBundle.es.yaml   # Sobreescrituras del bundle
└── validators/
    └── validators.es.yaml          # Mensajes del validador de Symfony
```

`messages.es.yaml` sigue una estructura estable; las claves de primer nivel más relevantes son:

| Clave                                    | Usado por                                                                               |
| ---------------------------------------- | --------------------------------------------------------------------------------------- |
| `app.messages.*`                         | Mensajes flash lanzados desde controladores / suscriptores                              |
| `admin.*`                                | Cadenas del panel de administración (inicio, perfil)                                    |
| `public.*`                               | Cadenas del sitio público (inicio, login, registro, recuperación, privacidad, cookies)  |
| `email.*`                                | Fragmentos de asunto / contenido para emails transaccionales (ver [email](14-email.md)) |
| `entities.<entity>.singular` / `.plural` | Etiquetas de entidad resueltas por `AbstractCrudController`                             |
| `entities.<entity>.sections.<section>`   | Encabezados de paneles de formulario / detalle                                          |
| `entities.<entity>.fields.<field>`       | Etiquetas de campo                                                                      |
| `entities.<entity>.actions.<action>`     | Etiquetas de acciones personalizadas (p. ej. `impersonate`)                             |
| `entities.role.permissions.<permission>` | Etiquetas legibles para permisos no-CRUD                                                |
| `entities.user.fields.genders.<case>`    | Claves de traducción del backed enum (`UserGender`)                                     |

`AbstractCrudController` expone los helpers de convención `transEntitySingular()`, `transEntityPlural()`, `transEntitySection()`, `transEntityAction()` y `transEntityField()`, todos enraizados en `entities.{transEntity}.*`.

`UserGender` (`src/Entity/Enum/UserGender.php`) implementa `TranslatableInterface` y resuelve claves bajo `entities.user.fields.genders.{caseName}`.

## Añadir un nuevo locale

1. Añade el código a `LOCALES` en `.env` / `.env.local` (p. ej. `LOCALES='es|en|fr'`).
2. Crea `translations/messages.<locale>.yaml` (y los archivos de sobreescritura de bundle necesarios) copiando desde `messages.es.yaml`.
3. Traduce `validators/validators.<locale>.yaml`.
4. El locale aparecerá automáticamente en el selector de EasyAdmin y pasará la lista permitida de `LocaleSubscriber`.
